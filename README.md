Our Final Year Project "SignWhispers" aims to bridge the gap in communication between mute persons who cannot speak and normal individuals. <br>
Mute persons use their own Sign Language which they use to communicate among themselves but normal persons often find themselves unaware of that language and there occurs a communication gap between them. <br>
<br>
We built our custom American Sign Language ASL dataset of approximately 5500 data samples recorded using OpenCV + MediaPipe. We have used machine learning techniques "Random Forest Algorithm" that classifies the gestures performed by the mute persons into English alphabets in real time and produce a short string of words on screen achieving 94% accuracy.
<br>
Additionally, user can choose his desired language from the dropdown menu in which he wants the text on the screen to be and can even listen to the generated text as well. 
<br>
<br>
<b>Tech Stack used:</b> 
<br>
~ React.js for fontend 
<br>
~ Python FastAPI for backend
<br>
~ ML technique "Random Forest Algorithm" for classification purposes
